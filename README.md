# Automatic Sensor-Based Water Tap

## Overview
A touchless water dispensing system using an IR sensor and relay-controlled pump to improve hygiene and reduce water wastage.

## Features
- Contactless operation  
- Automatic water flow control  
- Real-time response  

## Components / Technologies
- IR Sensor  
- Relay Module  
- DC Motor Pump  
- Power Supply  

## Working
The IR sensor detects the presence of a hand → activates the relay → relay turns on the pump → water flows → stops automatically when no detection.
